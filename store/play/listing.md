## Full description (4000 max) — 3254 chars

```
JoDoo is a to-do and shopping list app built on a simple idea: a list app should open instantly, work everywhere, and not ask who you are.

There is no sign-up screen, no email prompt, and no password to forget. You install it and start typing.

TO-DO LISTS

Keep as many separate lists as you like — work, home, projects, packing, whatever you need. Each task can carry a description and a due date, and every task card is tinted so a long list stays readable at a glance. Drag tasks to reorder them, and check them off when they are done.

SHOPPING LIST

A dedicated section built for the way people actually shop. Type an item, give it an amount, and check it off in the aisle. JoDoo learns the items you buy and suggests them as you type, so your regulars take only a couple of keystrokes.

WORKS OFFLINE, GENUINELY

JoDoo stores your lists in a database on your phone. Not cached from a server, not synced down at launch — stored. Every feature works on a plane, in a basement, or on a dead network, because nothing in the app needs a connection to function.

That also means it is fast. There is no spinner while a list loads, because there is nothing to wait for.

READABLE AT ANY SIZE

Set the text size to something you can read across the kitchen or from a coat pocket. The setting sticks.

Switch between your to-do lists and your shopping list from the bottom tab bar, or with a two-finger swipe.

OPTIONAL SHARING — REQUIRES YOUR OWN SERVER

Sometimes a list needs a second person: a shopping list your partner adds to on the way home, or a project list shared with a colleague. JoDoo can sync a list live between devices, without accounts.

Please read this part before relying on it. New Leaf Software does not run a JoDoo server. There is no service to sign up for and no address filled in for you. If you want to share lists, you or someone you trust must run the JoDoo sync server, which is free and open source under the MIT license, and enter its address in the app's settings. It runs comfortably on a home machine, a Raspberry Pi, or the cheapest tier of any cloud host.

When you share a list, it is given a short share key that is easy to read aloud or send in a text message. Anyone who enters that key can see and edit the list, and changes flow between devices live.

Sharing a list means storing that list on the server you configured. That is what allows several people to work from the same list. Shared lists are deleted automatically after thirty days without an update, and you can stop sharing at any time. Lists you have not shared are never sent anywhere and stay only on your device.

If you never set up a server, none of this applies — JoDoo is simply a fast local list app, which is how most people use it.

WHAT JODOO DOES NOT DO

• No account, no login, no email address
• No advertising
• No analytics, telemetry, or third-party tracking libraries
• No data collection — there is nothing gathered to sell

JoDoo requests a single permission, INTERNET, and uses it only for the optional sharing described above. It asks for no access to your contacts, location, camera, microphone, photos, or files.

Privacy policy: https://newleafsoftware.com/jodoo-privacy.php

From New Leaf Software, LLC — Boulder, Colorado.
```
